**Non-blocking (note, by design):** English-identical values are reported as warnings only and never fail the build (`return 0`). This is explicitly documented in the module docstring, and the hard guarantee this gate provides is *key presence* (which IS enforced for all required locales). Flagging only so it's a conscious choice: if "must not be left in English" is meant to be CI-enforced rather than advisory, this loop would need to append to `failures` instead of `warnings`. No change required for the story's acceptance criteria.
