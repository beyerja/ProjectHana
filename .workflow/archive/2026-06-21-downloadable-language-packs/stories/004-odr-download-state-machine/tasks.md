## Tasks

- [x] 001: Add a `ResourceRequesting` protocol (test seam) wrapping `NSBundleResourceRequest`. Declare the minimal surface the ODR provider needs — `loadingProgress` (fractional 0...1), an async/closure `beginAccessingResources` that completes with success or error, `endAccessingResources`, and `conditionallyBeginAccessingResources` for an already-present check. Add a `LiveResourceRequest` conformer that owns a real `NSBundleResourceRequest` (init with tag set + bundle), plus a factory closure type `(_ tags: Set<String>) -> ResourceRequesting` so production wires the live request and tests inject a fake. NO network/crypto/hash/signature code — ODR integrity is inherited from App Store code-signing; this seam only triggers and observes the download.

- [x] 002: Define the per-language ODR tag mapping. Add the ODR tag(s) for each downloadable language (fr/de/ko/nah) keyed off `AppLocale`/the catalog `availability == .downloadablePack`, in one place (e.g. extend `LanguageDescriptor`/`LanguageCatalog` with an `odrTags` accessor or a dedicated `ODRTagCatalog`). Base languages (en, es-MX) have no tags and are NEVER requested. Cover the mapping with a small unit test asserting base languages yield no tags and each downloadable language yields its expected tag(s).

- [x] 003: Add an observable `LanguagePackDownloadState` machine modeling per-language pack state: `notRequested → downloading(progress: Double) → available`, plus `failed(retryable: Bool)` with a `retry` transition back to `downloading`. Make it an `@Observable` (or `ObservableObject`) per-language store keyed by `AppLocale` so the picker (story 005) can observe fractional progress and the failure/retry affordance. Map these states onto the existing `LanguagePackState` (`available`/`notDownloaded`/`downloading`/`failed`) the provider already exposes, keeping the provider seam's `state(for:)` contract unchanged. Pure-logic unit tests for every transition (request→progress→success; request→failure→retry→...).
