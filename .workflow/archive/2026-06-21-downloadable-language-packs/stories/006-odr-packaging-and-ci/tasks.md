## Test fallout (handled)
Moving the non-base `.lproj` to ODR removed them from `Bundle.main`, so 3 content tests that assumed always-bundled `.lproj` failed (`L10nBundleResolutionTests` ko/nah; `LocalizedQuizPromptTests` German continent). The simulator unit-test host has no asset-pack server, so `NSBundleResourceRequest` cannot mount ODR into `Bundle.main`. Added `HanahuacTests/ODRTestSupport.swift` (loads a pack's `.lproj` directly from the on-disk built asset pack, skips if unreachable) and rewrote the affected tests to: (a) validate shipped pack content directly from the asset pack (skip-if-unreachable), and (b) assert the no-download offline fallback chain (ko/nah → es-MX → en, never the raw key). Country/river NAME tests are unaffected — those resolve from the still-bundled `countries.json`/`rivers.json` via `BundledLanguagePackProvider`.
